# מדורת השבט: שלושה קולות

אתר הסדרה "מדורת השבט" על תולדות הציונות הליברלית בישראל: איך חילונים, מסורתיים ודתיים בנו יחד את הציונות ואת מגילת העצמאות, ומה קרה לברית הזו מאז.

אתר סטטי, בלי שלב build. GitHub Pages מגיש אותו ישירות מענף `main`.

## מבנה

| קובץ | מה יש בו |
|---|---|
| `index.html` | הדף כולו: עיצוב, ציר הזמן, הקורא |
| `data/hub.json` | התזה, החוטים, ולכל פרק: שנים, hook, כרטיס 30 שניות, שלושת הקולות, ציטוט ומקורות |
| `content/postNN.md` | הטקסט המלא של כל פרק (Markdown) |
| `content/intro.md` | ההקדמה |
| `assets/marked.min.js` | ספריית Markdown (מקומית, בלי תלות ב-CDN) |

## איך עורכים

- **לתקן טקסט בפרק:** עורכים את `content/postNN.md`. זה הכל.
- **לשנות את הכרטיס בציר הזמן:** עורכים את הרשומה המתאימה ב-`data/hub.json`.
- **פרק חדש:** מוסיפים `content/post15.md` ורשומה חדשה ב-`eras` עם `"post": 15`.

## הרצה מקומית

```
python3 -m http.server
```
ואז http://localhost:8000. פתיחה ישירה של `index.html` מהדיסק לא תעבוד כי הדף טוען קבצים ב-fetch.

## לפני שמשיקים לציבור

- להסיר את שורת `<meta name="robots" content="noindex, nofollow">` ב-`index.html`.
- לעבור על רשימת הנקודות הפתוחות לבדיקה (במסמך "נקודות פתוחות" בתיקיית הסדרה בדרייב).
